## Play and build

1. Extract the entire archive. Open `game/project.godot` with the **standard Godot 4.7.2 editor**. Allow time for the first asset import and press **F5**. Select **New game** or load a previous save.
2. Download the matching standard export templates. Unzip the template pack and copy `macos.zip`, `windows_release_x86_64.exe` and `windows_debug_x86_64.exe` into `.tools/templates/` under the extracted folder. You can also set these paths in Godot's Export dialog. [Official editor and templates](https://github.com/godotengine/godot-builds/releases/tag/4.7.2-stable) · [Matching engine source](https://github.com/godotengine/godot/tree/4.7.2-stable)
3. To reproduce the desktop exports on a Mac, install Python 3, set `GODOT_BIN` to the Godot executable, and run `bash tools/build-native.sh` from the extracted folder. The script imports the source, collects third-party notices and exports the macOS and Windows presets, and writes the matching source ZIP to `builds/`. To build one target manually, use the corresponding preset in Godot's Export dialog. The official Mac build used ad-hoc signing. Signing and import metadata can change package bytes on another computer.
4. When distributing the binaries online, place the matching source archive beside them and make it accessible for free. Recipients can run and export this project offline after installing the editor and templates.

## Edit this edition

Use the original Godot scripts in `game/`, the native export presets and all the resources used by those presets. The chapter Git bundle is available separately for exploring the incremental development checkpoints.

- Edit the dialogue in `tools/build-story.py` and the evidence, controls and hints in `tools/early_puzzles.py` and `tools/late_chapter_puzzles.py`. Run `python3 tools/build-story.py` to update the campaign, transcript and walkthrough. Read the full dialogue in `docs/campaign-transcript.md`.
- Edit case notes, timelines, matches, routes and their hints in `tools/early_caseboards.py` and `tools/late_caseboards.py`. Rebuild with the same story command. You can follow every case in `docs/campaign-walkthrough.md`.
- We estimate 3.5 to 5 hours for a first playthrough. At 2 to 2½ minutes per stage, the 84 stages across 32 case boards account for 168 to 210 minutes. We allow another 42 to 90 minutes for the rest of the story, navigation and remaining puzzles. We have yet to time first-time players.
- For walking scenes, edit the navigable floor and object approach points in `game/content/illustrated-floor.json`. The original walk cycles and acting poses are in `assets/characters/campaign/performance/`. Rebuild their runtime sheets with `tools/pack-exploration-actors.py`. Recreate the footstep recordings with `tools/build-footfalls.py`.
- Find scenery and foreground originals in `assets/environments/`, character paintings and facial landmarks in `assets/characters/`, and the chapter animation keyframes in `assets/cinematics/campaign/`. Change the drawn frames or regenerate their motion maps with `tools/prepare-chapter-animations.py`.
- Edit the chapter action sequences in `game/content/films.json`. You can adjust the editing originals in `assets/cinematics/campaign/films/` and prepare the in-game pictures with `tools/prepare-story-films.py`.
- Edit the dialogue WAVs, matching timing data, or stereo ambience. The original voice recordings, cue sheets, FLAC and WAV masters are under `assets/audio/`. The first Archivist recording is under `assets/characters/archivist/voice/`. All in-game recordings are included locally.
- Find all 30 soundtrack MP3s in `game/assets/audio/music/`. Edit the title, chapter, interlude and epilogue cues in `game/content/music.json`, then run the illustrated campaign from `game/project.godot`. The cue sheet in `assets/audio/soundtrack/` lists the supplied filenames and recording measurements.
- For native checks on a Mac, run `bash tools/test-campaign.sh --render` from the extracted folder. The suite covers all chapters, case boards, story timing, saves, movement, staging, soundtrack and film ownership. Set `NIGHT_NINE_QA_AUDIO_DRIVER=Dummy` for automated runs without physical sound output. Rendered tests are capped at 60 FPS. See `docs/toolchain-provenance.json` for editor and template checksums.
